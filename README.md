# Customer Retention Analytics Dashboard

## Project Overview
This project analyzes customer churn and retention patterns for a telecom subscription-based business using Power BI.

The objective of the analysis is to identify:
- Customer churn patterns
- Key retention drivers
- Customer lifetime value trends
- Revenue impact of churn

The dashboard provides actionable business insights that can help improve customer retention and reduce revenue loss.

---

# Tools Used
- Power BI
- Excel/CSV Dataset

---

# Dataset
Dataset used:
Telco Customer Churn Dataset

The dataset contains customer-level information including:
- Contract type
- Tenure
- Internet service
- Payment method
- Monthly charges
- Total charges
- Churn status

# Key Insights

## Churn Patterns
- Month-to-month customers showed the highest churn.
- Customers within the first year were most likely to leave.
- Fiber optic users had relatively higher churn concentration.

## Retention Drivers
- Long-term contracts improved retention significantly.
- Higher tenure customers demonstrated stronger loyalty.
- Retained customers contributed higher long-term revenue.

## Customer Lifetime Trends
- Two-year contract customers generated the highest total revenue.
- Customer lifetime value increased with retention duration.

---

# Business Recommendations
- Improve onboarding for early-tenure customers.
- Introduce incentives for long-term contracts.
- Strengthen retention strategies for fiber optic users.
- Use predictive churn indicators for proactive retention campaigns.

---

# Business Impact
This project demonstrates how retention analytics can:
- Reduce customer churn
- Improve customer lifetime value
- Increase recurring revenue
- Support data-driven business decisions
